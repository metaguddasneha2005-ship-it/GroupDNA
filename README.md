# GroupDNA – WhatsApp Group Chat Analyzer

## 📌 Overview
GroupDNA is a Python-based project that analyzes WhatsApp group chats and generates useful insights about group activity and participants.

## ✨ Features
- Chat parsing
- Group activity analysis
- Most active day and hour
- NumPy activity heatmap
- Top 10 common words
- Response time analysis
- Silent streak detection
- Personality archetypes
- Final formatted report

## 🛠️ Technologies
- Python
- NumPy
- File I/O

## 🧠 Concepts Used
Strings, Lists, Dictionaries, Sets, Tuples, Loops, Conditionals, Functions, NumPy, and File I/O.
